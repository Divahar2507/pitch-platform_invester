# Backend Development Plan

## Objective
Focus exclusively on backend development using FastAPI, PostgreSQL, and Python.

## Your Responsibilities
*   **Database Models:** Define tables in `app/models`.
*   **API Endpoints:** Create routes in `app/routes`.
*   **Business Logic:** Implement logic in routes or services.
*   **Testing:** Test APIs using Swagger UI (`http://localhost:8000/docs`) or Postman.
*   **Migrations/Schema:** Manage database schema using SQLAlchemy.

## Collaboration with Frontend
*   **API Contract:** Agree on JSON response structures with your frontend friend.
*   **Swagger Documentation:** Use the auto-generated docs to share API details.
*   **Git Strategy:** Push your changes to a `backend` branch or coordinate merges.
